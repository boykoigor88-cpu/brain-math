# Брейн Эволюция — адаптивная версия

HTML-игра с исходным визуальным оформлением `premium.css` и сохранёнными режимами.

## Запуск
Откройте `index.html` или разместите все файлы из этой папки вместе на GitHub Pages. Дополнительный файл `adaptive.js` обязателен — он отвечает за локальную адаптацию. Для Tailwind и конфетти (как и в исходной версии) нужен интернет.

## Что изменилось
- В **«Обучении»** система ищет устойчивые трудности **по математическим приёмам**, а не по конкретным выражениям. Новые упражнения подмешиваются примерно в 4 из 15 позиций при наличии подтверждённого затруднения.
- Не менее двух отдельных сессий, шести наблюдений и четырёх разных заданий нужны для выявления проблемного навыка. Проверяются повторные ошибки или аномально медленные верные ответы относительно медианы той же операции и сложности.
- Первое решение примера учитывается один раз, подсказки/повторные попытки не добавляют ложную статистику.
- **Спринт, тайм-атака и выживание не адаптируют подбор**, но собирают наблюдения в основной профиль (не в гостевом режиме).
- В новой **«Карте навыков»** можно посмотреть статистику по математическим закономерностям.
- Математические советы показываются после сессии и в разделе навыков. Отчёт для ИИ теперь экспортирует карту навыков вместо «карантина».
- Старые рекорды и статистика (`brainmath_records`) сохраняются. Старый `brainmath_quarantine` оставлен в localStorage без изменения, но новая версия его не использует.
- История навыков хранится отдельно в `brainmath_skill_history_v1` в том же браузере. Автоматическая синхронизация между телефонами не предусмотрена.

### Проверка
В репозитории доступны `tests/adaptive.test.js` — локальные тесты генератора/аналитики на Node.js (`node tests/adaptive.test.js`).
